# MAKATON – Phrases en pictogrammes

Application web (un seul fichier, `index.html`) : on écrit une phrase, chaque mot devient un pictogramme.

- Dictionnaire intégré d'environ 300 mots du quotidien (conjugaisons, pluriels, féminins gérés)
- Pictogrammes modifiables : emoji, image personnelle
- Génération automatique d'une image pour les mots inconnus (nécessite l'environnement Claude)
- Impression de la phrase

Ouvrir `index.html` dans un navigateur.
